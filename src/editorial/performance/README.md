# Intelligent Performance & Semantic Trimming Engine (RF-056)

Motor determinista y proposal-first para la optimización semántica de secuencias audiovisuales en el Motor Editorial v4.0.0.

## Componentes
- `SemanticRedundancyEngine`: Detección de solapamiento semántico e informativo con protección estricta de evidencia probatoria.
- `BestTakeSelector`: Selección ponderada de tomas con desempate determinista sin aleatoriedad.
- `NaturalPerformancePreservation`: Protección de risas, respiraciones expresivas y pausas reflexivas frente a errores técnicos descartables.
- `IntelligentTrimmingEngine`: Orquestador con control de límites físicos, padding editorial, micro-crossfades y protección contra sobrepoda (> 30%).
